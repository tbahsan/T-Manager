Everything it does

Every action shows a before → after preview and a quota cost estimate before it runs.

✏️

Batch rename + numbering

4 modes — replace, prepend (keep your original title), append, custom template. Per-kind prefixes: শর্ট-১, লং-২ — real Bangla digits.

🖼️

Batch thumbnails

One image for every selected video, or per-video mapping. Client-side validation, side-by-side preview. (Shorts 9:16 builder in progress.)

📝

Batch descriptions & tags

Replace / append / prepend with {existing} and {date} placeholders. Tag merge that skips duplicates, 500-char guard.

⬆️

Upload queue

Drop many files, get auto-numbered titles. Resumable 5 MB chunks survive network cuts. Mandatory privacy & made-for-kids pre-flight.

📊

Analytics dashboard

Views, watch time, subscribers, CTR — plus an estimated revenue / RPM card for monetized channels. Cached 6h so it's quota-cheap.

👥

Multi-channel

Connect several channels and switch in one click. Cache, history, quota log and analytics stay perfectly separated per channel.

↩️

Full undo

Every batch snapshots before writing — restore the whole batch in one click. (Delete is the one exception: it's triple-gated instead.)

⚡

Quota tracker

YouTube's API costs units — T-Manager tells you the exact price of a batch before you run it, and tracks daily usage locally.

Install in 3 steps

~2 minutes · works while the extension is pending store review

Download & unzip

Grab the Chrome or Firefox zip above and extract it to a folder you'll keep.

Chrome: load it

Open chrome://extensions → enable Developer mode → Load unpacked → select the unzipped folder.

Firefox: load it

Open about:debugging#/runtime/this-firefox → Load Temporary Add-on… → pick manifest.json.

🔐 Why the permissions? T-Manager asks only for identity (Google sign-in), storage (your local cache/history) and access to googleapis.com (the YouTube APIs themselves). There is no server, no telemetry, no analytics leaving your device — all code is open source, read it yourself.

FAQ

Short answers, honest ones.

Is it really free?

Yes — MIT licensed, source on GitHub. The only costs are Google's free API quota limits, shown to you transparently.

Does it work for Bangla titles?

বাহ! That's the flagship feature — numbering supports Bangla digits (১, ২, ৩…), per-kind prefixes like শর্ট/লং, zero-padding, and "continue from last number".

Can it break my channel?

Every write shows a before → after preview and creates an undo snapshot first. Batch delete is the exception: it's irreversible by Google's API, so it needs selection + confirmation + typing DELETE.

Where is my data?

On your device. Video cache, history and settings live in your browser's local storage. No server, no accounts, no telemetry.

Store listing?

Chrome Web Store + Firefox Add-ons (incl. Android) are planned for the v1.0 release (~Dec 2026). Meanwhile the zip install above works fully.
