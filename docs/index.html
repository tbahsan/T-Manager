Features

Everything in one pass

Every action shows a before → after preview and its quota cost before it runs — and can be undone after.

✏️

Batch rename + numbering

4 modes — Replace · Prepend (keep original) ⭐ · Append · Custom. Per-kind prefixes: শর্ট-১ লং-২, Bangla or English digits, zero-pad, and custom text before/after the number — with a live example under every mode.

↩️

Full undo

Every batch snapshots before writing. One click restores titles, descriptions & tags.

⬆️

Resumable uploads

Multi-file queue with auto-numbered titles. 5 MB chunks survive network cuts & restarts.

🖼️

Batch thumbnails

One image for all, or per-video mapping. Client validation + side-by-side preview. (9:16 Shorts builder — soon)

📊

Analytics + revenue

Views, watch time, subs, CTR — plus a revenue & RPM card for monetized channels. 6h cache keeps it quota-cheap.

📝

Descriptions & tags

Replace / append / prepend with {existing} · tag merge that skips duplicates · 500-char guard.

👥

Multi-channel, zero mix-ups

Connect several channels, switch in one click. Cache, history, quota and analytics stay perfectly separated per channel — and switching is locked while a job runs, so nothing ever lands on the wrong channel.

⚡

Quota honesty

YouTube's API costs units — T-Manager shows the exact price of every batch before running, tracks daily usage locally, and hard-gates uploads at 1,600u each.

Install

Up and running in 2 minutes

Works while the extension waits for store review — no build tools needed.

Download & unzip

Grab the Chrome or Firefox zip above and extract it to a folder you'll keep.

Load it

Chrome: chrome://extensions → Developer mode → Load unpacked. Firefox: about:debugging#/runtime/this-firefox → Load Temporary Add-on…

Connect YouTube

Click the T-Manager icon → Connect YouTube → allow the permissions. Done ✅

🔐 Why these permissions? Only identity (Google sign-in), storage (your local cache/history) and googleapis.com access (the YouTube APIs themselves). No server, no telemetry — nothing ever leaves your device. The whole codebase is open; read it yourself.

FAQ

Straight answers

Is it really free?

Yes — MIT licensed, source on GitHub. The only limits are Google's free API quotas, shown to you transparently before every action.

Bangla titles — really?

That's the flagship: real Bangla digits (১ ২ ৩…), per-kind prefixes like শর্ট/লং, zero-padding, custom text around the number, and "continue from last number" so series never restart by accident.

Can it break my channel?

Every write shows a before → after preview and snapshots an undo first. Batch delete is the one irreversible thing (Google's API), so it demands selection + confirmation + typing DELETE.

Where is my data?

On your device — browser local storage only. No server, no account, no telemetry. Uninstall and everything is gone.

Store listing?

Chrome Web Store + Firefox Add-ons (incl. Android) are planned for v1.0 (~Dec 2026). The zip install above works fully meanwhile.

How do I report a bug or ask for a feature?

Right here on GitHub — bug report · feature request. Forms take a minute; you'll be notified the moment your item ships.
