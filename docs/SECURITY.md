# Security Policy — T-Manager

> Maintained by Tasneem Bin Ahsan (TBA) · github.com/tbahsan

- No client secret ships in the extension (browser `identity` flow only).
- No analytics data, tokens, or channel metadata ever leave your device. No telemetry, no server.
- Minimal permissions: `identity`, `storage`, `unlimitedStorage`; host access limited to `https://www.googleapis.com/*`.

## Reporting a vulnerability
Please use GitHub **Security Advisories** (private) or the support email on the store listing. Do not open a public issue. Fixes targeted within 7 days.
